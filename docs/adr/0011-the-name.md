# 0011 — Constancia

2026-08-27 · Accepted

## Context

The working name was FitCore. It turned out to be occupied rather than merely unavailable:
[fitcore.pt](https://fitcore.pt) is a live platform for trainers and gyms — workout templates,
exercise logging, diet plans, progress statistics, chat, and an AI training assistant. Same
name, same category, same core idea. Beyond that: a fitness wearables brand, a Los Angeles
studio, a health club, and an app already on Google Play.

That is a discoverability problem before it is a legal one. An MIT repo whose whole purpose is
being found would have sat behind four fitness companies.

## Decision

**Constancia** — `constancia.fit`.

Renamed while the cost was 41 mentions across 20 files and a single commit that did not contain
the name. Three weeks later it would have been the repo URL, the Twilio number registration and
Meta's business verification, which binds to a name.

## Consequences

The word carries two meanings in Spanish and the product is both:

- **perseverance** — the Stoic virtue, consistency over intensity
- **an official record** — *constancia laboral*, *constancia de estudios*

Worth knowing which arrives first. In Colombia and Mexico the bureaucratic sense dominates
everyday use, so a Spanish speaker hearing the word cold thinks "certificate" before "discipline".
The `.fit` suffix disambiguates instantly, and both senses point the same way — a record of what
you actually did. But the name lands as *your record* more than *your discipline*, and copy
should lean into that rather than fight it.

Pronounceable unchanged in Spanish and English, which matters because voice is the primary input
and users say the name aloud.

## Alternatives

Greek and Latin coinages were the main branch explored — *Askesia* (athletic training plus
self-discipline), *Diaitica* (regimen as a whole way of living), *Metronia* (measure), *Hexis*
(disposition built by repetition). All were clean and available; all read as proper nouns, which
was the objection.

Metaphor names were the other branch — *Cairn* (a path marked one stone at a time), *Tessera*
(one tile of a mosaic), *Urdimbre* (the warp threads everything is woven onto), *Bitácora* (a
ship's log). Strong images, but short English words are gone and the good Spanish ones are
ordinary vocabulary.

*Constancia* won because it is a real word in the user's language that already means the thing,
rather than a coinage that has to be taught.
